What Is a Bit? Think of a Light Switch

A bit is the smallest unit of information a computer uses. It can have only two values, usually written as 0 and 1. You can picture it as a light switch: off or on. One switch alone does not say much, but billions of them working together can represent almost anything.

Computers use this two-value system because it is reliable and simple to build with electronics. A tiny circuit can easily tell the difference between a low and a high electrical signal, so each switch is either clearly off or clearly on.

Binary is just a way of counting with those two digits. Instead of the ten digits (0 to 9) that we use every day, binary uses only 0 and 1, and each position stands for a power of two.

Bits, Bytes and Bigger Units

Because single bits are tiny, we group them. These are the units you will see when checking file sizes and storage.

bit

A single 0 or 1. Internet speeds are often described in bits per second.

byte

Eight bits. Roughly enough to hold one character of basic text, such as a letter.

KB

Kilobyte, about a thousand bytes. A short plain-text note might take a few kilobytes.

MB

Megabyte, about a million bytes. A typical photo or a short audio clip is often measured in megabytes.

GB

Gigabyte, about a billion bytes. Apps, movies and games are commonly measured in gigabytes.

TB

Terabyte, about a trillion bytes. Large drives and backups are measured in terabytes.

A small note: some systems count in thousands, while others use powers of two such as 1,024. That is one reason a drive can show slightly less space than the number printed on its label.

How Text, Pictures and Sound Become Numbers

Computers only handle numbers, so everything else has to be translated. The idea is the same each time: agree on a code, then store the numbers.

Text

Each character is given a number through a standard code. Modern systems such as Unicode cover letters, symbols and emoji from many languages.

A = 65 B = 66 a = 97

Images

A digital picture is a grid of tiny dots called pixels. Each pixel's colour is stored as numbers for how much red, green and blue it contains.

red = 255, 0, 0 white = 255, 255, 255 black = 0, 0, 0

Sound

Sound is measured many thousands of times each second, and each measurement is stored as a number. Played back in order, they recreate the sound.

sample 1 = 0.12 sample 2 = 0.35 sample 3 = 0.41

File Formats and Compression

A file format is the agreed way of arranging data so that software knows how to read it. The ending of a file name, such as .txt, .jpg or .mp3, usually hints at the format.

Lossless Compression

Makes a file smaller without losing any information. When you uncompress it, you get back exactly what you started with. This approach is used for documents, program files and some image and audio formats.

Lossy Compression

Makes files much smaller by discarding details that people are less likely to notice. Many photo, music and video formats use this. Compressing too aggressively can reduce quality, and the lost detail cannot be recovered.

Compression is why a photo can be shared quickly and a movie can be streamed over a normal internet connection. Different tools and settings offer different trade-offs between size and quality.

Where Data Is Kept: A Simple Tour of Storage

Memory (RAM) is fast, temporary workspace. It holds what your device is using right now and is cleared when power is lost.

Hard disk drives store data on spinning magnetic platters. They offer lots of space at a lower cost per gigabyte but are slower and more sensitive to knocks.

Solid-state drives use flash memory with no moving parts. They are typically quicker and quieter, and are common in modern laptops and phones.

Cloud storage keeps copies on remote servers, so files can be reached from different devices when you are online.

Handy Habits for Everyday Data

Understanding how data works makes a few simple routines feel natural.

01

Back up important files. Keep copies in more than one place so one failure does not mean losing everything.

02

Check free space. Devices slow down or struggle to update when storage is almost full. Delete what you no longer need.

03

Name files clearly. Descriptive names and dates make files easier to find later.

04

Choose sensible formats. Use widely supported formats for files you plan to share or keep for a long time.

05

Handle drives gently. Eject external drives safely and avoid knocks, heat and moisture.

06

Protect personal data. Be careful about what you store and share, and keep passwords private.

Frequently Asked Questions

Why do computers use binary instead of normal numbers?

Two-state signals are simple and reliable to build in electronics. Everything else is represented by combining many bits.

What is the difference between a bit and a byte?

A bit is a single 0 or 1. A byte is a group of eight bits.

Why does my storage show less space than advertised?

Manufacturers and operating systems may count units differently, and some space is used by the system itself and by formatting.

Can compressed files be restored to the original?

Lossless compression can be fully reversed. Lossy compression cannot, because some detail has been permanently removed.
